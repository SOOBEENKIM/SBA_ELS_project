# 출처·무결성·재현 기록

## 저장한 최종 실행

- 계약조건/월지급형: `analysis/mc_monthly_v3_20260910`.
- 관측 횟수/만기 추가 평가: `analysis/mc_schedule_v4_20260911`.
- 독립 지급원장·NumPy MC·실패 사례 재추론: `analysis/mc_v3_audit_20260910`.

최종 계약 엔진 `mc_contract_v2.py`, `mc_contract_v3.py`, 모델 정의 `models.py`, 입력 인코더 `common.py`, 계약 생성 규칙과 **9개 `.pt` 가중치의 바이트를 보존**했다. 원본 MC 라벨과 유지한 예측값을 바꾸지 않았다. 원문 CSV 3종도 무손실 압축했으며 복원 후 원본 해시를 검사한다.

`export_lineage.json`은 원본 파일과 내보낸 파일의 해시를 기록한다. `mc_monthly_v3_20260910_artifact_manifest.json` 등 날짜 이름이 붙은 파일은 **원래 작업 폴더의 이력 기록**이며, 제외된 과거 비교 파일도 나열할 수 있다. 이 내역은 수정하지 않았다. 실행용 manifest는 각 실험 폴더에 따로 있으며 새 저장소에 실제 포함된 파일을 검증한다.

## 내보내면서 정리한 부분

1. 오류가 있던 예전 `mc_engine.py`, 과거 MC 학습 라벨, PI·Stage 2 실험은 제외했다.
2. `evaluate.py`는 최종 세 학습 방식만 평가하도록 과거 모델 비교 블록과 외부 폴더 의존성을 제거했다. `filtered_results.json`에 결과 행 수의 변화를 기록했다. **남긴 행의 MC/모델 수치는 변경하지 않았다.**
3. `module/networks.py`에서는 쓰지 않는 과거 클래스만 제외했다. 현재 쓰는 `mlp`, `CurveOperatorV2`의 AST가 원본과 동일함을 확인했다.
4. 기존 `els3_dataset.parquet`는 현재 템플릿 추출에 필요한 **상품 ID 열만** 남겼다. 과거 지급률 근사를 새 계약 입력으로 사용하지 않는다. 원문에서 표본 58,790개의 ID 집합을 다시 검증한다.
5. 과거 폴더 이름이 붙은 보조 입력은 계약 86개와 공시 6개의 시장 상태만 추출했다. MC 가격·학습 자료를 과거 버전에서 가져오는 경로가 아니다.
6. 사용하지 않는 비교 그림·역사적 보고서 생성기는 제외하고, `scripts/summarize_results.py`로 현재 결과표를 읽어 README 마지막, `docs/RESULTS.md`, `Report_2.md`를 만든다. 새 `scripts/run.py`는 새 실행 폴더를 만들어 결과를 격리한다.
7. 일정 실험의 보존 입력 해시는 내보낸 최종 3방식 예측 CSV를 가리킨다. 원래 사양은 `schedule_original_label_spec.json`에 별도로 보존했다. 계약·MC 수치·가중치 변경을 숨기기 위해 과거 해시를 덮어쓴 것이 아니다.

## 실행 환경

원래 설치된 이미지 ID는 `sha256:72cf4a76ff63e6109e8e3710d7c7835ffd96564483eaf6d55f7581524adb1054`다. 이 ID는 원래 환경의 식별 기록으로, 다른 컴퓨터에서 바로 pull 가능한 공개 이미지 주소는 아니다.

Python 3.11.15, torch 2.9.1+cu126(CPU 연산), numpy 2.3.0, pandas 2.3.0, scipy 1.16.0, pyarrow 20.0.0, matplotlib 3.9.2, pillow 12.3.0, python-dateutil 2.9.0.post0, holidays 0.104를 사용했다. `requirements.txt`와 `Dockerfile`에 해당 환경을 명시했다. 공식 Python 기본 이미지 태그의 존재도 확인했다.

이번 업로드에서는 전체 Docker 이미지를 새로 다운로드·빌드하거나 9개 모델을 다시 학습하지 않았다. 원래 완료한 9개 학습 이력과 가중치를 보관하고, 동일 버전의 설치된 환경에서 **깨끗한 파일 복원·MC 전량 재계산·고정 가중치 재추론**을 수행했다. `full`은 같은 학습 코드를 처음부터 실행할 수 있는 경로이며 새 실험 결과로 제시한 것은 아니다.

## 업로드 전 검증

검증 상세는 [publish_validation.json](publish_validation.json)과 동봉한 실행 기록을 기준으로 한다. MC·모델의 실제 재현 오차와 완료 상태를 이 파일에 저장한다. 환경 의존적인 학습 결과까지 모든 하드웨어에서 비트 단위로 일치한다고 주장하지 않는다.

실제 재계산 대조 결과: 계약조건 실험 **85,440개 시나리오**의 MC 가격·증분·표준오차 최대 차이 **5.46e-12원**, 일정 실험 **3,003개 시나리오**는 **0원**이었다. 두 실험의 생성 계약도 모두 일치했다. 깨끗한 복원 폴더의 131,328행 모델 재추론 최대 차이는 **1.819e-12원**이었다. 이는 저장값과의 재현 일치이며 모델 예측 오차가 0이라는 뜻이 아니다.
